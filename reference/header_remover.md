# header_remover

상단에 존재하는 헤더를 제거합니다.

## Usage

``` r
header_remover(df)
```

## Arguments

- df:

  BigKinds 원본 문서

## Examples

``` r
df <- data.frame(
  "일자" = c(20230101, 20230102, 20230103),
  "언론사" = c("조선일보", "한겨례", "경향신문"),
  "제목" = c("[속보] 경찰, 민주노총 도심 집회 1차 해산명령", 
              "[사설] 한반도 긴장 높인 북한의 군사정찰위성 발사 규탄한다",
              "‘직권남용죄’ 남용 유감"),
  "키워드" = c("경찰,해산명령,민주,노총,도심,집회,해산,명령,민주노총",
                "한반도,긴장,북한,규탄,군사,정찰,위성,발사,북한,인공위성",
                "직권남용죄,남용,유감,왜냐면,이정환,민주사회,변호사모임"))
                
data <- header_remover(df)
head(data)
#>       일자   언론사                                                제목
#> 1 20230101 조선일보               경찰, 민주노총 도심 집회 1차 해산명령
#> 2 20230102   한겨례  한반도 긴장 높인 북한의 군사정찰위성 발사 규탄한다
#> 3 20230103 경향신문                              ‘직권남용죄’ 남용 유감
#>                                                    키워드
#> 1    경찰,해산명령,민주,노총,도심,집회,해산,명령,민주노총
#> 2 한반도,긴장,북한,규탄,군사,정찰,위성,발사,북한,인공위성
#> 3  직권남용죄,남용,유감,왜냐면,이정환,민주사회,변호사모임
```
